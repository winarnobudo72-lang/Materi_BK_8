1. Pencarian Data dengan Fungsi Lookup

Fungsi Lookup digunakan untuk mencari data tertentu dalam sebuah tabel acuan berdasarkan nilai kunci.

  • VLOOKUP (Vertical Lookup): Mencari data pada tabel acuan berformat vertikal (kolom).
    =VLOOKUP(nilai_kunci, tabel_acuan, nomor_kolom, [range_lookup])
  • HLOOKUP (Horizontal Lookup): Mencari data pada tabel acuan berformat horizontal (baris).
    =HLOOKUP(nilai_kunci, tabel_acuan, nomor_baris, [range_lookup])

2. Pencarian Data dengan Fungsi Reference

Fungsi referensi digunakan untuk mengambil alamat atau posisi data di dalam lembar kerja:

  • INDEX: Mengambil nilai sel berdasarkan posisi baris dan kolom tertentu dalam suatu rentang data.
    =INDEX(array, nomor_baris, nomor_kolom)
  • MATCH: Mencari posisi urutan (index) baris atau kolom dari suatu nilai dalam rentang satu dimensi.
    =MATCH(lookup_value, lookup_array, [match_type])
  • Referensi Alamat Sel:
    • Relatif (A1): Berubah saat rumus disalin ke sel lain.
    • Absolut ($A$1): Nilai sel tetap/terkunci total saat disalin.
    • Semi-Absolut ($A1 / A$1): Terkunci hanya pada kolom atau baris saja.

3. Visualisasi Data (Data Visualization)

Visualisasi data adalah proses menyajikan data angka dalam bentuk grafik agar mudah dipahami trend dan komparasinga.

  • Grafik Batang (Column/Bar Chart): Cocok untuk membandingkan antar kategori data.
  • Grafik Garis (Line Chart): Sangat baik untuk menampilkan tren data dari waktu ke waktu (time-series).
  • Grafik Lingkaran (Pie Chart): Menampilkan proporsi atau persentase kontribusi komponen terhadap total.

4. Peringkasan Data (Data Summarization)

Peringkasan data bertujuan menyederhanakan data berukuran besar menjadi informasi terpusat.

  • Fungsi Statistik Bersyarat:
    • COUNTIF: Menghitung jumlah sel yang memenuhi satu syarat tertentu.
    • SUMIF: Menjumlahkan nilai sel berdasarkan satu syarat tertentu.
    • AVERAGEIF: Menghitung rata-rata nilai sel berdasarkan satu syarat tertentu.
  • Pivot Table: Fitur interaktif untuk meringkas, menganalisis, mengelompokkan, dan mengeksplorasi ribuan baris data secara cepat tanpa mengetik rumus manual.
